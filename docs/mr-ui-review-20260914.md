## 本轮修复

1. **切片滑块与已显示的中间层不一致**：例如已显示 17/32，滑块仍停在 0。异步加载中层号先于范围到达，Qt 提前钳位后没有重新计算。滑块现在同时依赖范围与当前层号；32 层和 192 层影像已复核，并增加确定性的延迟范围回归。
2. **辅助功能操作只改勾选外观、未执行实际动作**：通过 macOS 辅助功能接口选择序列或 MPR 布局时，界面状态和控制器状态可能不一致。通用按钮与复选框现在使用完整点击动作，补齐序列行的可访问名称／操作；取消、重新选择和四宫格切换已在最终窗口复核。此项是在辅助功能激活路径发现的，不将普通鼠标路径描述为同样失败。
3. **多选工作区恢复后活动序列错误**：旧实现固定取第一个已选序列，可能使侧栏 3D 按钮打开另一组影像。现在持久化活动序列；缺少新字段的旧文件回退到最后选中项。覆盖了活动项位于多选列表中间的保存恢复回归。
4. **MR 组按哈希 ID 排列**：改为按源序列、数值时相、回波及分量等维度稳定排序，侧栏与对照选择器一致，避免 t=10 排在 t=2 前等难以浏览的顺序。
5. 调窗提示移除 CT 专属措辞；对照视图切换时为空标题加默认值，消除相应 QML 警告。

## 验证边界与复查入口

本轮桌面工具的画布坐标拖拽多次返回“找不到窗口”；这些失败的工具操作没有计作通过，ROI 与 3D 裁剪由上述原生 Qt 鼠标回归补查。跨方向 Alt 定位、全部旋转／镜像／压缩组合没有在本轮桌面操作中穷尽，已有合成回归不能替代每种实际采集协议的验收。

目前真实样本覆盖 Siemens、Philips、Canon 的所列数据；尚缺 GE 和更广泛的 T2／FLAIR 等协议验收。Mosaic、MR 4D 播放、融合、ADC／DTI／灌注／fMRI 分析及厂家定量换算仍是明确未实现项。MR 3D 是强度体绘制，不是组织分割。

本地证据目录：`/Users/jun/Documents/Voxenra-MR-TestData/ui-review-20260914`。从软件的“工作区 → 打开工作区”选择其中的 `enhanced-review.voxworkspace`，可恢复这次保存的对照和 MPR 场景；其源路径仍指向 Documents 下的原始样本，不依赖临时启动器。

- `thin-t1-mpr-anonymous.png`：本轮实际桌面操作导出的活动 MPR 视口。
- `native-artifacts/`：原生回归生成的 ROI、四窗、MPR、灰度／高信号／MIP 和 padding 截图及逐组参考校验记录。
- `native-crop-artifacts/`：MR 裁剪与重置的实际 VTK 输出。
- 普通 QML 窗口截图可能不含嵌入的原生 VTK 子窗口；3D 判断以单独保存的 VTK 图像及实际桌面截图为准。
