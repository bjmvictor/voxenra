# Voxenra v1.2.0

本版本改善日常阅片操作、序列导入和大体数据加载体验。

## 新增与改进

- 2D 视图左上角提供高亮的视图选择器，使用完整名称 **Stack、Axial、Coronal、Sagittal**。明确区分原始切片与标准切面的 2D MPR，保留位置及四角信息。
- 测量默认保留两位小数，可在设置中选择整数或 1–3 位小数；ROI、VOI、分析结果及测量报告使用一致的显示精度，原始计算值不变。
- 默认鼠标左键拖动调窗、右键拖动缩放、滚轮翻页；当前工具、十字线等专用交互优先。融合配准保留右键旋转，3D 滚轮保持缩放。
- 收起后的左侧栏保留导出、清除等操作；序列展开按钮更易点击，影像类型更醒目。右侧窄栏提供可展开的测量、旋转、标注和伪彩分组，底部按钮统一为重置所有。
- 工作区副本位置支持悬停查看、复制及在文件管理器中打开。恢复或丢弃后自动关闭工作区对话框。手册移除重复标题，正文支持选中复制。

## 修复

- 修复侧边栏提示首次出现时位置跳动及二级工具视觉区分不足的问题。
- 修正异常重复 SOP Instance UID 的识别，使用文件元信息区分可识别的独立文件，避免误跳过有效影像；空间重复和不规则数据仍进行重建校验。
- 正常导入结束后自动关闭进度窗口；存在重复、跳过或错误时保留结果供确认。
- MPR 切面偏离标准方向后正确显示 Oblique；独立旋转 3D 相机不改变切面名称。
- 修复原生 3D 空闲循环重绘，以及快速切换页签后已销毁页面继续执行延迟回调的问题。体数据数组准备移到后台；关闭视图取消旧读取，过期结果不再回写，缓存按预算回收。

## 验证与边界

已完成 CT、MR、Enhanced MR、PET、测量及窗口交互回归，并用真实 CT / MR 和大体积 CT 验证重复加载、切换、导出和关闭。优化保持原始像素、分辨率和患者坐标；首次 GPU 绘制仍可能短暂停顿。

提供 macOS Apple Silicon DMG、Windows x64 安装版与便携版，以及各自的 SHA-256 校验文件。macOS 沿用 ad-hoc 签名，Windows 包未做 Authenticode 签名；不代表 Apple 公证或商业代码签名。
