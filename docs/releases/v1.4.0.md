# Voxenra v1.4.0

本版本新增线斜坡 FWHM / 层厚分析，增强 MTF 与水模 QA 工具，改进测量卡片设置和 3D 渲染健壮性。

## 新增功能

- 服务工具新增 **FWHM** 线斜坡分析：沿单根线斜坡取样测量半高宽，并换算层厚 Slice Thickness = FWHM × tan θ。默认 23°（Catphan），可切换 45°；支持高斯拟合与半高交点法，剖面图随结果展示。FWHM 与 MTF 的 ROI、分析方式、结果和重置互不影响。
- MTF 分析增强：默认高斯拟合；检出显著负旁瓣时自动采用边缘加权 FFT（Tukey α=0.5），并在结果中标注本次使用的分析方式。频率单位可在 lp/mm 与 lp/cm 间切换，同步曲线横轴与 MTF50 / MTF10 标注。
- 水模 QA 统计表每行可复制附加圆形 ROI：副本独立移动与取样，单独显示均值、SD、Δ中心，不参与五区均匀性与噪声汇总；副本可删除，初始五区受保护。
- 测量设置新增「指标与卡片」分组：卡片与图形联动开关（关闭后卡片可独立拖动）、指标字号与卡片背景透明度，右侧提供实时预览。
- 设置分组折叠状态跨会话记忆；设置页新增 GitHub 项目主页入口。

## 操作与显示改进

- MTF / FWHM / 水模 QA 结果标题旁新增「分析方式与质量提示」弹窗，展示本次计算方式、适用条件与质量警告。
- 3D 渲染更稳健：OpenGL 不可用时明确提示原因与处理建议；渲染错误附带具体诊断信息；HiDPI 与大窗口自动限制屏幕空间采样密度，拖动与静止采用同一质量路径，避免画面跳变。
- 测量卡片与图形默认独立移动，联动行为可在设置中开启；标签拖动即时反映在结果数据中。
- 内置操作手册同步更新 MTF / FWHM 与水模 QA 章节，说明新工具的用法与结果边界。

## 结果说明

斜坡层厚换算仅适用于与影像 X / Y 对齐的单根线斜坡，不做模体倾斜校正；结果不代表层间距，也不以 DICOM 标称层厚替代实测。附加 QA ROI 是独立取样点，不改变五区协议的汇总指标。分析结果仍不自动判定合格。
