# Voxenra v1.1.0

新增 MR 支持，完善多视口阅片、序列对比与工作区，并更新功能图集。

## 主要更新

- **MR 与 Enhanced MR**：支持经典单帧和增强多帧灰度 MR，按回波、扩散、时相及分量分组；提供自动调窗、反白、测量，规则序列支持 MPR 与 3D。
- **布局与多窗口**：2D 预设／自定义网格、拖拽序列到视口、方向切换；MPR 多种布局及带切面参考的 3D 四宫格，页签可分离为独立窗口。
- **序列对比**：2–4 序列 2D 对比、双序列 MPR 六宫格与对应切面放大；可控的位置、旋转、窗值与显示比例联动，各视口独立测量。
- **工作区与记录**：保存／恢复影像引用、布局和操作状态，自动恢复副本；测量标注撤销重做、复制粘贴，支持 CSV / PDF 导出。
- **交互与稳定性**：修复联动调窗实时显示、切片滑条与手册章节滚动状态；完善紧凑边栏、深浅主题及中英文界面。
- **文档与示例**：重写精简 README，补充 30 张功能截图和 4D 动画，明确影像、归档和解码支持范围。

MR 重建以规则的单个浏览组为单位；分组浏览不包含 fMRI / DTI 分析或 MR 4D 播放。对比联动不执行自动配准。详见 [影像支持说明](https://github.com/l5769389/voxenra/blob/v1.1.0/docs/image-support.md)。
