# Voxenra v1.3.0

本版本完善分割结果交换与测量报告，扩展影像读取能力，并改善 3D、MPR 和窗口布局。

## 新增功能

- 自由形状 ROI：沿边界绘制、闭合统计、编辑及撤销重做，可将选中 ROI 转为单层分割。
- DICOM SEG 导出与导入：多个区域可合并导出，保留名称、颜色与空间引用；右侧独立导入工具加载匹配当前影像的 SEG，并支持管理和再次导出。
- DICOM SR 结构化测量报告：输出带单位、空间位置及原影像引用的测量结果；分割统计输出对应 SEG，平面测量单独成报告。
- Enhanced CT / Legacy Converted Enhanced CT 多帧与线性定量显示映射；内置固定版本的 RLE、JPEG、JPEG-LS、JPEG 2000 解码组件。
- CT 3D 扩展为 20 个显示模板，默认 AAA；改善光照、采样与调窗对颜色及透明度的联动。

## 操作与显示改进

- 2D 选择器明确区分原始切片与轴位、冠状位、矢状位重建，并解释实际方向与位置信息。
- MPR 四宫格中激活任意切面或 3D 均可切换布局；支持记忆布局、双击放大 3D 和返回四宫格。
- 独立 3D 与四宫格采用适配视口的初始取景，完整展示并保留边距；旋转时保持用户的放大倍率。
- 切片播放与 CT 多时相播放分开控制；4D 的分割和 VOI 按时相保存。
- 主窗口默认 1440×900、最小 1280×720；独立窗口默认 1120×840、最小 960×720。侧栏调整保留阅片空间，设置导航适配最小窗口。
- 无法打开的影像仍创建页签，显示具体原因并提供关闭入口；PNG 导出状态与实际可用性一致。
- README 更新全部现有功能截图，新增结果工具截图和 4 段操作动画，现共 34 张静态图、5 段动画。

## 结果格式说明

左侧导入原始影像，右侧导入关联 SEG。SR / RTSTRUCT 导入暂未提供。SEG / SR 保留源身份与影像引用，不应用普通影像导出的匿名选项。

Slicer 已用于 SEG 与影像显示交叉验证；Slicer 对自由形状等平面测量 SR 的读取仍有限制，可用 PDF / CSV 查看数值。

## 安装包

提供 macOS Apple Silicon DMG、Windows x64 安装版和便携版，以及各自的 SHA-256 校验文件。

macOS 沿用 ad-hoc 签名，Windows 包未做 Authenticode 签名；不代表 Apple 公证或商业代码签名。
