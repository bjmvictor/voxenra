# Voxenra v1.5.0

本版本改进 MTF 分析的负旁瓣处理与结果展示，并打磨测量工具的若干交互细节。

## 主要变化

- MTF 负旁瓣处理改为高斯等效 MTF：检出显著负旁瓣时不再使用边缘加权 FFT 包络，改为以实测 MTF10 锚定的标准形态曲线，MTF50 随之恢复合理比例，曲线平滑单调。
- 点源 MTF 移除「分析方式」选择：统一按原始 LSF 直接 FFT 计算，负旁瓣自动切换高斯等效，实际使用方式仍以文字标注。
- MTF 面板新增「方向」选择：X / Y 曲线与指标可单独或同时显示，默认只看 X，至少保留一个方向；图表图例与方向选择联动。
- 测量工具排序调整：自由形状移到测量工具组末尾。
- 自由形状 ROI 绘制过程中隐藏顶点操纵点，减少干扰；测量卡片交互与样式细节调整。

## 安装包

提供 macOS Apple Silicon DMG、Windows x64 安装版和便携版，以及各自的 SHA-256 校验文件。

macOS 沿用 ad-hoc 签名，Windows 包未做 Authenticode 签名；不代表 Apple 公证或商业代码签名。
