# 4D 双播放、分割 / VOI 与底栏验证

## 实现范围

- 展开侧栏底部操作行统一为 40 个逻辑像素，按钮高 32；收起侧栏每个操作占 40 像素。无重置操作时隐藏重置按钮，保留收展入口。
- 播放、重置和清除等操作按钮保留背景和边框，禁用时降低文字 / 图标对比度。
- 4D 提供当前时相切片播放与跨时相播放，图标区分普通播放 / 停止和 4D 播放 / 停止；两种播放互斥，展开和收起侧栏均可操作。
- CT 4D 使用 MPR 的阈值分割和 VOI。记录、源体素、统计和遮罩按时相隔离，清除只影响当前时相，工作区保存全部时相记录。不包含自动传播、追踪或时序统计。

## macOS 原生界面

使用文稿中 10-21-1997-NA-p4-86157 的 CT 数据，在隔离的临时设置和工作区下运行完整 Main.qml。共 10 个时相，每时相 149 张切片。通过 QTest 鼠标点击和拖动验证：

1. 当前时相播放改变切片且保持时相；4D 播放改变时相；停止保留当前位置。
2. 在时相 1 实际拖动绘制阈值分割，在时相 2 绘制 VOI，均产生有效统计和三切面范围。
3. 切换时相隐藏上一时相范围，返回恢复；清除时相 1 不删除时相 2 的记录。
4. 保存 / 恢复后正确恢复时相 2 的 VOI。
5. 收起侧栏可分别启动和停止两种播放。
6. 底栏实际高度为 40，禁用清除仍有按钮外观；检查截图无截断、无重叠，无 QML 警告。
