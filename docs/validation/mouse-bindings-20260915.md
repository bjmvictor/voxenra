# 视口鼠标默认操作验证（2026-09-15）

## 行为

- 2D／MPR／对比／4D 切片视图：默认左键调窗、右键缩放、滚轮翻页。平铺沿用滚轮浏览网格。
- 当前工具使用左键；十字线、定位点、VOI／分割控制点及测量编辑保留各自优先级。QA 未命中 ROI 时左键调窗。
- 右键缩放不改变选中工具，不修改窗值、切面或测量数据，未完成的角度测量可以在缩放后继续。
- PET／FUSION 手动配准保留左键平移、右键旋转；定位十字线左键仍优先。
- 3D（含 MPR 四宫格参考视图）右键缩放，左键执行所选工具（默认旋转），滚轮继续缩放。参考定位圆环左键移动定位，右键不改变 MPR 位置。
- 拖动光标按实际按钮操作锁定，ROI 左键仍从首个像素位移开始反馈。README 与中英文离线手册同步更新。
