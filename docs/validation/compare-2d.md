# Compare 2D 验证记录

日期：2026-09-14。所有交互测试使用合成影像和临时配置。

## 功能范围

- 左侧勾选两组序列后，从展开或折叠侧栏的右键菜单直接创建 Compare 2D 页签。
- 右键单组序列进入选择界面，列出其他支持 2D 的影像，显示患者、序列、检查日期和切片数；同患者优先排列。缺少候选时显示导入提示。
- 两侧复用标准 2D 控制器，共用一个翻页滑块，支持不同切片数量、单张影像和 CT / PET 混合来源。重复打开同一组合时激活原页签。
- 翻页、调窗、平移、缩放、旋转、镜像、伪彩、反白和显示信息默认同步，可逐项关闭。重新启用时从当前视口同步；关闭翻页同步后滑块仅控制选中视口。
- 翻页按相对进度对应，不进行空间配准。混合模态的窗值含义不同，可关闭调窗同步后分别调整。测量、标注独立，报告可包含两侧结果。
- 工作区保留两个来源、两侧状态和同步选项；移动到独立窗口时保留控制器和撤销历史。
- 原生 3D 页面上的选择界面使用独立对话窗口，固定尺寸并使用系统关闭按钮。普通页面使用应用内弹窗和右上角关闭按钮。
- 右侧工具区固定预留滚动条空间，避免窄面板中文字换行与滚动条反复改变宽度、造成布局循环。
