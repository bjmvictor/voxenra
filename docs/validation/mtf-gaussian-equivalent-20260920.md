# MTF10 锚定的高斯等效显示

## 定义与用途

设置 → 测量与标注 → MTF 新增 **高斯等效（基于 MTF10）**，按用户要求默认开启。设置自动保存，重启保留；切换即时应用于现有结果，无需重新绘制 ROI。关闭后显示原始实测频谱及独立计算的 MTF50/MTF10。

对于可靠的实测 MTF10，定义：

```text
M(f) = exp[-ln(10) × (f / MTF10)²]
MTF50 = MTF10 × sqrt[ln(2) / ln(10)] ≈ 0.548662 × MTF10
```

由 M(MTF10) = 0.1 及 M(MTF50) = 0.5 直接推导。模型以零频响应 1 归一化；绘图中包含精确的两个阈值交点，保证曲线和标记、数值一致。单位换算应用于所有频率，系数不受 lp/mm 或 lp/cm 影响。

这是**模型估计**，不是对 LSF 的高斯拟合，也不是独立实测 MTF50。它将响应约束为单调高斯形状，不能表示锐化带来的超调或非高斯响应；曲线更平滑不代表物理测量更准确。不能以换算后接近某个预期数值作为正确性证明。

## 数据与失效处理

- 原始分析缓存不变；开启仅变换展示结果，关闭完整恢复。ROI 支持、背景校正、FFT、MTF10 交点与敏感性检查仍按[实测方法](mtf-final-20260920.md)计算。
- MTF10 缺失、非有限、非正或被敏感性检查判为不可靠时，该方向不生成曲线和 MTF50，不用另一方向或 FWHM 代替。
- 若仅实测 MTF50 不可靠，而 MTF10 可报告，可以给出明确标记的等效 MTF50。原始质量提示仍收在信息按钮中，并加“实测频谱”前缀。
- 方法标签、ROI 指标卡标明“高斯等效”；公式和含义放在设置说明及信息弹窗内。
- 独立 FWHM、斜坡层厚计算和结果完全不变。等效曲线没有用于反推 FWHM。
