## 自动回归

`tests/test_tab_windows.py` 使用合成影像和真实 QML 页面覆盖：

- 深色／浅色 × 中文／英文的菜单、右键目标、拖动排序、Esc 取消和中键关闭。
- 鼠标拖出新建窗口、拖回合并、内容区取消、空主窗口的拖放区域、边缘滚动。
- 窗口内关闭其他／右侧／全部、窗口级快捷键、主窗口关闭与重新显示、最后一个窗口取消退出。
- 2D、平铺、MPR、PET、融合、4D、标签、设置、手册、PACS 页面迁移；保留控制器、测量及历史。
- 加载中移动、失败重试、关闭后过期回传、迁移失败回退及旧页面回调隔离。
- 所有窗口的测量报告范围、工作区保存顺序及恢复到主窗口。

完整回归使用 `tests/run_isolated.py` 按文件隔离 Qt 引擎。最后修改涉及的页签、平铺和三维测试另行重跑；日志中的第三方弃用提示不等同于 QML 绑定警告。

桌面鼠标抓取测试仅在原生平台执行；离屏插件不具备正常桌面拖放环境，在连续模拟跨窗口抓取时曾触发 Qt 内部崩溃。离屏测试保留拖放目标、排序和取消逻辑检查，真实鼠标拖出／拖回单独在 Cocoa 验收。

## macOS 原生窗口

在 Cocoa 平台运行 `tests/test_tab_windows.py`，使用实际窗口和 Qt 鼠标／键盘事件，验证拖出、跨窗口拖回、菜单和快捷键。没有用离屏平台代替此项。

`tests/manual/smoke_tab_windows.py` 使用临时配置和合成 CT/PET 数据，验证 CT、PET、融合 3D：

- 复用原生宿主与体数据，拆分、返回及源页面延迟销毁后画面仍可见。
- CT/PET 的裁剪、撤销／重做，三种三维页面的显示参数与相机状态。
- 深浅主题、中英文、原生全屏及退出全屏；PNG 画面包含有效渲染内容。
- 无 QML 警告或已销毁对象回调异常。

从项目根目录运行，`PYTHONPATH` 需包含 `src` 和 `tests`：

```sh
PYTHONPATH=src:tests python tests/manual/smoke_tab_windows.py /tmp/voxenra-tab-windows
```

截图保存到指定临时目录，不加入发布资源。融合 3D 验证已有相机与显示功能；现有融合 3D 不提供 CT/PET 单体裁剪工具。

## 待平台实测

当前没有 Windows 实机，也没有多屏幕和混合缩放比例环境。Windows 原生标题栏、拖出／拖回、原生 3D 重挂载、最后窗口关闭行为，以及多屏幕尺寸限制仍需分别验收。

多窗口共用控制器与渲染资源，窗口级控制器仅维护归属、顺序及当前选择。原生画面采用 [Qt WindowContainer](https://doc.qt.io/qt-6/qml-qtquick-windowcontainer.html)，通过挂载身份和场景挂载确认拒绝旧页面回调；创建的独立窗口归 QML 引擎管理生命周期。
