# 播放组合检查 · 2026-09-16

## 发现并修复

1. **未加载的 4D 也能进入播放状态。** 原先只检查时相数量。现要求切片已就绪、MPR 状态有效；四宫格 3D 出错时也不能启动跨时相播放。展开、收起侧栏和播放面板共用此判断。
2. **停止后仍可能执行排队的时相请求。** 停止时丢弃尚未提交的时相请求，已提交的帧允许完成；在时相切换完成前禁用“当前时相播放”，避免读到尚未提交的时相。
3. **工作区恢复后播放模式与面板不一致。** 保存、恢复播放模式，兼容旧工作区根据工具类型推断；恢复始终保持停止并释放工具锁。
4. **工作区显示的 FPS 与计时器不同。** 复现保存 12 FPS、恢复后显示 12 而实际间隔仍为 500 ms。恢复改用统一的 `setFps`，两种 4D 播放均验证恢复为 83 ms。

## 检查范围

- 2D：Stack、Axial、Coronal、Sagittal，末帧循环、渲染繁忙等待、切换模式、空白格子、缩减布局隐藏当前格子。
- MPR：切片播放与三个切面空间定位同步；CT、MR、PET 的相关渲染路径；MR 窗值在播放后保持。
- 4D：当前时相切片播放与跨时相播放互斥；切换模式必须先停止；加载、错误、排队请求、FPS、时相切换、工具锁、分割/VOI 的组合。
- 布局与生命周期：同一切片最大化、布局变化、选中 3D、关闭/切换标签、移到独立窗口再移回、恢复工作区后计时器停止且工具解锁。
- 侧栏：展开/收起均验证播放/停止状态及禁用另一种播放按钮。
- 原生 3D：MPR 四宫格双击最大化/恢复，保持相机和模板；4D 在最大化的 3D 视口中可跨时相播放。
