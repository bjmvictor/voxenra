# 启动与体积优化验证

日期：2026-09-21。基线：`6b0f4f6`。本次仅修改源码与构建配置，未构建、推送或发布新安装包。

## 启动

macOS arm64 / Python 3.13.14；同一开发依赖环境，Qt offscreen / software，禁用 QML 磁盘缓存，空白工作区、临时配置，各启动五个独立进程。基线使用该提交的源码副本，优化版使用当前源码；均未加载用户影像。操作系统文件缓存未清空，所以不是冷启动成绩。

| 阶段（中位耗时） | 基线 | 优化后 |
| --- | ---: | ---: |
| Qt 与应用模块导入、创建 QApplication | 0.313 s | 0.228 s |
| 控制器构造 | 0.074 s | 0.016 s |
| QML 主界面加载 | 0.310 s | 0.277 s |
| 依赖导入开始至首帧 | 0.746 s | 0.537 s |

首帧中位耗时减少约 28%。空白工作区加载的 VTK 原生 Python 模块由 9 个降为 0，highdicom 不再提前加载。加载成本转移到首次使用相关功能，算法和像素处理不变。

工具：`tests/manual/benchmark_startup.py`。各阶段独立取中位数，因此不能直接相加替代首帧中位数。

## 体积

现有本地 macOS 应用包按非符号链接文件统计为 406.2 MiB，其中 VTK 194.0 MiB、Qt 二进制 98.3 MiB。这些运行库的主要部分仍为 3D 和桌面界面所需，不能通过无差别删除来减小体积。

对同一个已安装 Qt 的真实 QML 收集清单应用优化前后钩子：

| QML 直接收集项 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 文件数 | 294 | 103 |
| 文件字节数 | 11,648,142 | 1,474,591 |

直接减少 10,173,551 字节，约 9.70 MiB。统计包含 QML 插件与其资源，不包含二进制依赖递归收集、签名和压缩；**不能把它当作最终安装包缩小量**。Windows 和 macOS 最终包体积需下次实际构建后测量。

增加 Windows `--portable-dir` 构建选项，避免单文件 EXE 每次启动解包；安装版原本就使用目录布局。原有单文件构建和发布流程保持兼容。本轮未测量 Windows 解包耗时。
